# MyOllama - macOS Native Chat Client

ローカルで稼働している [Ollama](https://ollama.ai) と直接接続し、高速・プライベートにストリーミング会話ができるSwiftUI製のmacOSネイティブチャットアプリです。

## 主な機能

- **ローカルモデル自動検出**: Ollamaサーバーから利用可能なモデル一覧（`qwen3.8:27b-mlx`, `gemma4:12b-mlx`, `jp-fast:latest` など）を自動取得し、プルダウンで手軽に切り替え。
- **画像送信（マルチモーダル / Vision対応）**:
  - 📷 **画像添付ボタン**: ファイルダイアログから画像（PNG, JPEG, WebP, GIF, HEIC）を選択可能。
  - 🖱️ **ドラッグ＆ドロップ**: 入力欄に画像を直接ドラッグ＆ドロップして添付。
  - 📋 **クリップボードペースト**: `Cmd + V` でコピーした画像を即座に貼り付け。
  - プレビュー＆削除機能、自動リサイズ圧縮により高速・安定送信。
  - Vision対応モデル（`qwen3.8:27b-mlx` など）に `👁️` マークを表示。
- **思考モード (think) ON/OFF制御**: 推論モデル（Qwen 3.8 / 2.5、DeepSeekなど）向けの `think: true / false` フラグを入力バーや設定からワンクリックで切り替え可能。
- **思考プロセスのスマート表示**: `<think>` タグを自動パースし、折りたたみ（アコーディオン）形式でスタイリッシュに表示。
- **リアルタイムストリーミング**: `AsyncThrowingStream` & `URLSession.bytes` による低遅延なレスポンス描画。
- **英語学習アシスタント & メニューバー常駐**:
  - 📸 `Cmd + Shift + S`: 画面範囲選択 OCR（マウスでドラッグした領域の英語を読み取って辞書＆発音HUDを表示）
  - 🗣️ `Cmd + Shift + E`: 選択テキスト英語解説（ブラウザや他アプリで選択中の英文を即座に解説）
  - 🔤 英文コピー検知（`Cmd + C` / ダブル `Cmd + C`）: macOS内蔵英和辞書で **0.01秒・メモリ0MB** で意味・品詞・発音をHUDポップアップ
  - 💬 「文法・詳細解説」ボタンでOllamaに接続し、S+V+O+C構造分解・ずんだもん解説をオンデマンド実行
  - 🚀 メニューバー常駐: ウィンドウを閉じてもバックグラウンドで軽量待機（メモリ数十MB・CPU 0%）
- **操作性**:
  - `Enter` キーでメッセージ送信
  - `Shift + Enter` で複数行改行
  - 生成中の「停止（Stop）」ボタン
  - システムプロンプト（AIの振る舞い・性格）のカスタマイズ機能
  - チャット履歴のクリア

## 起動・ビルド方法

### 1. アプリの起動（ビルド済み .app）
```bash
./scripts/run_app.sh
```
または Finder から `MyOllama.app` をダブルクリックして開きます。

### 2. リリースビルド
```bash
./scripts/build_app.sh
```

### 3. コマンドラインからの開発・実行 (SPM)
```bash
swift run
```
